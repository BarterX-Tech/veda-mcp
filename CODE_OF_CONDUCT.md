# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, and keep discussions technical.
Instances of unacceptable behavior may be reported via the contact
methods in [SECURITY.md](SECURITY.md); maintainers will respond as soon
as practical and keep reporters' identities confidential.
